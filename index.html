How AccessCheck works

Automatic mutation detection without manual rescanning
01
Inspect computed DOM styles & labels

Reads actual rendered styles via window.getComputedStyle and tracks live DOM mutations via MutationObserver.

02
Calculate mathematical contrast

Computes relative luminance and contrast ratios strictly against WCAG 2.1 AA specs.

03
Refresh automatically when design changes

Recalculates automatically after a 350ms debounce whenever colors, classes, or styles mutate.

04
Recommend practical fixes

Provides copyable CSS and HTML recommendations you can apply directly to your code.
